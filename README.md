# 个人知识体系

Java 后端开发知识库，涵盖框架原理、中间件实践与面试准备。

## 模块说明

| 模块 | 内容 |
|------|------|
| [TestModule](TestModule/src/main/java/tech/jinguo/test/interview/README.md) | 面试准备：算法、数据结构、并发、设计模式 |
| SpringAssemble | Spring IoC / AOP / MVC / WebFlux 示例 |
| KafkaAssemble | Kafka 生产消费 & Kafka Streams |
| RocketmqAssemble | RocketMQ 消息收发 |
| MybatisAssemble | MyBatis 映射与插件 |
| InfluxdbAssemble | InfluxDB 时序数据库集成 |
| RPCAssemble | RPC 框架示例 |

## 面试准备

详见 [TestModule 面试准备指南](TestModule/src/main/java/tech/jinguo/test/interview/README.md)，包含：

- **高频算法**：两数之和、反转链表、二分查找变体、LRU 缓存
- **数据结构**：最小栈、双向链表
- **并发编程**：生产者-消费者、单例模式（4种线程安全写法）
- **设计模式**：观察者模式、策略模式
